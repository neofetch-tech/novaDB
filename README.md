## About

novaDB is a modern visual database designer built with Rust, Tauri, React and TypeScript.

The goal of the project is simple:

- Design databases visually
- Generate SQL automatically
- Work with SQLite projects
- Manage schemas without writing SQL manually
- Integrate AI-powered assistance

---

## Features

### Database Designer

Create tables, columns and relationships using a visual interface.

### SQL Generation

Generate SQL code automatically from your database design.

### SQLite Support

Store and manage projects using SQLite.

### AI Integration

Generate and improve database structures using Gemini AI.

### Cross Platform

Built with Tauri for high performance and low resource usage.

## Development

Clone the repository:

```bash
git clone https://github.com/neofetch-tech/novaDB.git
cd novaDB
```

Install dependencies:

```bash
npm install
```

Run development mode:

```bash
npm run tauri dev
```

Build application:

```bash
npm run tauri build
```
